# Listing Asset Drafts

These are editable draft templates for Shopify App Store listing media.

Files:
- `feature-media-template.svg`
- `screenshot-1-upload.svg`
- `screenshot-2-tracking.svg`
- `screenshot-3-sync.svg`

Notes:
- All templates are `1600x900`.
- They are intentionally simple so they can be copied into Figma, Canva, or another editor.
- Replace placeholder panels with real app screenshots before publishing.
- `airplane-icon.svg` is the selected CC0 icon from SVG Repo.
